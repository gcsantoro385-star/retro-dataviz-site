[3.3] VALIDATION & OUTLIERS

Age must be an integer from 0 through 120; family size must be an integer from 1 through 30. Invalid numeric entries become blank. Valid values outside the Tukey 1.5 × IQR fences are flagged for review and retained. Latitude and longitude are range checked when present; plausible coordinates are retained without claiming they belong to a particular delivery area.

[3.4] CATEGORY NORMALIZATION

Leading and trailing whitespace is removed throughout. Recognized spelling and case variants are standardized. Unrecognized values are left visible for review; the page does not silently map them to a known group.

[3.5] TRANSFORMATION LOG

    [3.6] REPRODUCIBILITY

    All calculations run locally in this browser from the bundled dataset or a CSV selected above. The cleaned download preserves original column order and documents repaired blank or repeated header names; typed numeric values are serialized as plain CSV numbers. No missing values are imputed. Duplicate detection compares all columns after whitespace trimming and category standardization. The first matching record is retained. The original file is never overwritten.

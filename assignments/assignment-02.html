[2.6] BINARY CLASSIFICATION MODEL

LOGISTIC REGRESSION

A binary logistic regression classifier is used because the target variable, Output, contains two outcomes: Yes and No. The model estimates the probability that a respondent belongs to the Output = Yes class.

Numeric predictors are standardized and categories are one-hot encoded using the training set only. All four models use the same approximately 80/20 stratified group split (seed 42). Identical predictor profiles stay in one partition. Exact full-row matches are removed before splitting; this is a documented assumption because respondent IDs are unavailable.

[2.9] MODEL INTERPRETATION & LIMITATIONS

RESEARCH VALIDITY

Logistic regression is useful for this project because it connects the research questions to a binary outcome while remaining relatively interpretable. Positive coefficients are associated with a higher modeled probability of Output = Yes, while negative coefficients are associated with a lower modeled probability, holding the other encoded predictors constant.

A large coefficient should not automatically be described as a cause or as the "most important cause." The dataset is observational, categorical coefficients are relative to reference categories, and relationships between predictors can affect coefficient magnitude.

Feedback, Customer Type, and the unnamed duplicate of Output are excluded from every model. Customer behavior and feedback may be measured after ordering; their temporal relationship to the target is not established. The models address SQ1 and SQ2 as predictive associations. SQ3 still requires a separate descriptive analysis of feedback and behavior.

[METHOD] TRAINING & REPRODUCIBILITY

Models were trained in Python using scikit-learn and the actual XGBoost library. This HTML displays saved results; it does not retrain when opened. To process a changed dataset, rerun the supplied train_models.py, which updates the embedded results. The dataset is observational and the small holdout gives uncertain estimates; a higher score on this split is not proof of general superiority or causation.
